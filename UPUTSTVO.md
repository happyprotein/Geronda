# Постављање на GitHub Pages

1. На https://github.com/new направите **public** репозиторијум (нпр. `geronda`).
2. Пренесите садржај ове фасцикле: `index.html`, `sw.js`, `manifest.json`, `README.md` и цијелу фасциклу `icons/`.
3. **Settings → Pages → Deploy from a branch → main → / (root) → Save.**
4. За 1–2 минута апликација је на: `https://КОРИСНИЧКО-ИМЕ.github.io/geronda/`

Ако сте раније имали Mindful Broccoli на истом линку: кеш је промијењен (`geronda-v1`), па ће телефони сами преузети нову верзију. Ако се стара иконица задржи на почетном екрану, обришите је и инсталирајте поново.

При свакој будућој измјени повећајте број у `sw.js` (`geronda-v1` → `geronda-v2`).
