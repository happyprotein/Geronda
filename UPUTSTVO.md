# Постављање на GitHub Pages

1. На https://github.com/new направите **public** репозиторијум (нпр. `geronda`).
2. Пренесите **сав** садржај ове фасцикле: `index.html`, `sw.js`, `manifest.json`, `README.md` и цијелу фасциклу `icons/` (12 PNG иконица).
   Најлакше: отворите фасциклу на рачунару, означите све (Ctrl+A) и превуците одједном у GitHub прозор „Upload files“ — тако фасцикла `icons` иде са својим садржајем.
3. **Settings → Pages → Deploy from a branch → main → / (root) → Save.**
4. За 1–2 минута апликација је на: `https://КОРИСНИЧКО-ИМЕ.github.io/geronda/`

Слика старца је сада уграђена директно у `index.html`, тако да се приказује чак и ако нешто из фасцикле `icons` недостаје (тада би недостајала само иконица на почетном екрану телефона).

Ако на телефону и даље видите стару верзију: затворите апликацију/таб и отворите поново (кеш је `geronda-v14`). На Chrome-у може и: мени → Подешавања → Приватност → Обриши податке прегледања → Кеширане слике.

При свакој будућој измјени повећајте број у `sw.js` (`geronda-v14` → `geronda-v15`).

## Рад без интернета

Од ове верзије `index.html` је унапријед преведен и у себи садржи React, тако да се апликација отвара брзо и ради без интернета (послије првог отварања).

Фасцикла `izvor/` садржи изворни код (`src.html`) и скрипту `build.js` која из њега прави `index.html`. За обичан рад на GitHub-у она није потребна, али је сачувајте — у њој је извор свих будућих измјена.
