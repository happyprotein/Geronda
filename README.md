# Геронда

**Православна психотерапија** — бесплатна апликација за душевни мир.

- Јутарње и вечерње молитве
- Бројаница — Исусова молитва (33 чвора)
- Исповијест и Причешће — зашто су важни и како се припремити
- Мудрости из Светог Писма и Светих Отаца
- Свети Оци о души — туга, униније, страх и болест
- Дисање, физиолошки уздах, скенирање тијела, звучни пејзажи
- 36 вјежби за анксиозност, депресију, панику, социјалну анксиозност, стрес и смисао
- Дневник, захвалност, процјене (GAD-7, PHQ-9, PSS-10)

## Инсталација на телефон

**Android (Chrome):** отворите линк → мени (три тачке) → „Инсталирај апликацију“
**iPhone (Safari):** отворите линк → дугме за дијељење → „Додај на почетни екран“

## Кризне линије (БиХ)

- **СОС Бања Лука:** 1264
